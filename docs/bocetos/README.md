# Bocetos del tablero

Un boceto a mano (o en cualquier herramienta) por cada página definida en [01_requerimientos.md](../01_requerimientos.md#6-páginas-del-tablero). Una foto del papel alcanza.

| Archivo | Página | Estado |
|---|---|---|
| `01_resumen.jpg` | Resumen ejecutivo | Pendiente |
| `02_comercial.jpg` | Comercial | Pendiente |
| `03_logistica.jpg` | Logística | Pendiente |
| `04_cliente.jpg` | Cliente | Pendiente |
| `05_detalle_vendedor.jpg` | Detalle de vendedor | Pendiente |

Cada boceto debería mostrar dónde va cada visual, qué pregunta responde (código C1, L2, X3…) y qué filtros tiene la página. En la Fase 8 el reporte final se compara contra estos bocetos y contra los criterios de aceptación.
